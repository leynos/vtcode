# Diapason Zed Extension Status

The Zed extension manifest registers the local `diapason` executable as an ACP
agent server. No Zed registry listing or hosted Diapason binary assets are
published yet.

For local use, build or install Diapason from the repository source, then
install `extensions/zed-extension` as a development extension in Zed. See
[README.md](README.md) and [docs/QUICK_START.md](docs/QUICK_START.md).
